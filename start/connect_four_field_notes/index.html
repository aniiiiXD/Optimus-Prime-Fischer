Where CPU parallelism pays

One tiny forward pass was fastest on one thread (0.296 ms). A batch of 128 was faster on four threads (20.0k positions/s versus 11.8k/s). Four Pons processes did not beat one on our short queries.

PyTorch already vectorizes the model's matrix work. We sped up branchy game-rule code directly; no custom NEON kernel is claimed here.

The current play recipe

Each part has one job. The neural net is useful, but it is not asked to be the rules engine and the search tree at once.

01 · READEncode the board

42 board cells, side-to-move, and legal columns.

02 · RANKTransformer scores moves

Policy and Q estimates order the candidates.

03 · GUARDRules catch urgent tactics

Take a win; reject replies that leave a one-move loss.

04 · SEARCHAlpha-beta looks ahead

Depth 5, capped at 5,000 nodes in the measured setup.

05 · CHOOSEUse the best searched line

Hand-built leaf score; learned leaf-value weight is zero.

Strategies that earned their keep

These are the practical rules we learned from the runs—not a promise that any one trick makes the model unbeatable.

✳

Teach moves, not just endings

Search distillation before sparse-reward RL

A bounded alpha-beta teacher scores legal actions and supplies policy, Q, and value targets. That gives the CPU model useful feedback on each position instead of waiting for one win/loss signal at game end. Our training so far is supervised distillation, not RL.

keep
◉

Collect different kinds of boards

Phase balance + mixed trajectories

Mix random, center-biased, tactical, shallow-search, edge-biased, safe, and longer games. Sample openings, middlegames, and endgames; otherwise the net mostly memorizes one familiar opening or motif.

keep
⌁

Replay mistakes, but keep the basics

High regret + broad replay data

Mine states where the model's move is far below the teacher's best value, then label those again. Keep ordinary and earlier examples in the mix: training only on scary mistakes can make the model forget normal play.

keep
⊙

Make tactical labels physically true

A threatened column is not always a safe block

For every reply, simulate the drop and check the opponent's next wins. A real forced block must remove all immediate winning replies; if no move can, call it an unavoidable loss—not a missed block. Exact rules also take an immediate win ahead of neural preference.

keep
↔

Reuse equivalent work carefully

Mirror-canonical states + persistent labels

Left-right mirror boards share one teacher lookup, but the side to move stays in the key. Cache labels by board, player, and teacher settings; deduplicate exact states, not merely similar-looking boards. Split by opening group before adding extra training rows.

keep
⌕

Use the model to steer a small search

Neural ordering; adversarial lookahead

The Transformer ranks root moves, then alpha-beta considers the opponent's replies. Search found stronger play than the plain model in our local suite. The measured setting used handcrafted leaf evaluation: learned leaf values added cost without earning a promotion.

best measured
◇

Keep every experiment in its own lane

A better loss curve is not a stronger player

Save separate checkpoints, compare on the same held-out positions, swap colors on identical openings, and report regret, tactical misses, W/D/L, latency, and memory. We caught both a tactical-label bug and a candidate that looked good on its collected games but regressed on external holdout.

keep

What changed our minds

v4b → v5

More unique, balanced states helped. Held-out teacher-best agreement rose from 49.3% to 58.3%, and regret fell from 0.278 to 0.209. But Q/value MAE got worse and the game results stayed uneven by color.

Pons v1 → v3

Exact teacher labels need phase coverage. Late-game-only v1 did not raise overall search-opponent score. Phase-spread v3 learned Pons choices better, but still did not beat v5 against depth-3 search in that tournament.

DAGGER v1

Learning from our own games is promising, not automatic. The hybrid result was 2.5 points higher than the prior model, but its confidence interval included no gain and its exact-teacher holdout regressed, so we did not promote it.

What that human win means

It counts. Our 85% result is only against our local depth-3 search bot, not against you, the website bot, or a perfect-play solver. Those are different opponents.

A single game is a great bug-hunt: save the move history, mark the first high-regret choice, and identify the tactical motif. It is not enough by itself to rank checkpoints.

So: strong measured baseline, still beatable, and not a solved Connect Four player.

Measure the player, not the story

Every candidate needs to pass several views of the same problem. One attractive number can hide a bad side, a lost block, or a too-slow search.
