# Tic-Tac-Toe learning lab

```text
artifacts/
  models/   saved Q-tables and the trained MLP
  charts/   training and move-value plots
```

Run commands from this directory:

```bash
python3 train_and_visualize.py  # Q-learning self-play
python3 play_learned_ai.py      # play the Q-learning agent
python3 train_mlp.py            # train the CPU MLP from Minimax labels
python3 play_mlp_ai.py          # play the MLP
```

`learning_lab.html` is the original interactive explainer.
