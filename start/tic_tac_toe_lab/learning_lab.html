Why the MLP came next

A Q-table can leave rare tactical holes. An MLP shares its weights across similar patterns and can generalize.

Important detail

The MLP was trained by a perfect Minimax teacher. It is learned weights, but not trial-and-error reinforcement learning.

The methods are different tools

They can work together, but they solve the decision problem in different ways.

MethodWhat it stores or searchesLearning?Where it shines
Q-tableA separate score for every seen board and move.YesSmall games with manageable state spaces.

Then add a future.

A good early move might have no reward yet. It is useful because it leads to a later state with a good move.

After move 2 wins:
Q(B, move 2) = 0.200

Update move 1:
new Q(A, move 1)
= 0 + 0.2 × (0 + 0.95 × 0.2 − 0)
= 0.038

The winning value slowly travels backward: terminal win → late move → earlier move. That is how a Tic-Tac-Toe agent discovers blocks and forks without being handed a rule book.

Minimax is not learning

Minimax does not store weights or improve over time. It calculates a choice now by assuming both players act perfectly.

X tries move A · O chooses the minimum

O reply 1
X gets −1
loss
O reply 2
X gets 0
draw

O picks −1 because it is worst for X.

X tries move B · O chooses the minimum

O reply 1
X gets 0
draw
O reply 2
X gets +1
win

O picks 0 because it is worst for X.

X compares the branch values: max(−1, 0) = 0. X chooses move B and guarantees a draw. This is the Minimax pattern: my turn = max; opponent turn = min.
